How IntentFlow Works

Pre-Generation Intent Routing for Hallucination Mitigation & Cost Reduction

→
2

5

MATHDS

Math Solver (SymPy)

Arithmetic, algebra, and statistics offloaded to a deterministic computer algebra engine.

Zero arithmetic hallucination · 100% precision on benchmark computations.
TXTSRC

Search / Grounded RAG

Knowledge retrieval strictly grounded in verified reference corpora with source citations.

Eliminates entity hallucination · Controlled refusal outside indexed corpus.
SEMADPT

LLM Generator (Gemini)

Dispatched to foundation LLM for tone rewrites, creative writing, and open-ended dialogue.

Cost optimization · External API invoked only when generation is truly needed.
CSTRSET

Constrained Solver

Deterministic schema synthesizer enforcing strict JSON, YAML, XML, and length bounds.

Zero schema drift · Guarantees format compliance without conversational filler.
